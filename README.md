# ❤️ Heart Disease & 🏥 Insurance Cost — ML Projects

Two end-to-end tabular ML notebooks covering EDA, preprocessing and feature engineering.

| Notebook | Problem | Highlights |
|---|---|---|
| `heart.ipynb` | Predict presence of heart disease (classification) | EDA, data cleaning, scaling with `StandardScaler` |
| `insurance.ipynb` | Predict medical insurance charges (regression) | EDA, **Chi-square** and **Pearson** statistical tests, feature engineering, train/test split |

Datasets (`heart.csv`, `insurance.csv`) are included.

## Tech stack
Python · pandas · NumPy · scikit-learn · SciPy · Matplotlib · Seaborn

## Run it
```bash
pip install pandas numpy scikit-learn scipy matplotlib seaborn jupyter
jupyter notebook
```
